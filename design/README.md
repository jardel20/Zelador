# Referências de design

- `mockups/`: as 6 telas finais (v3) em HTML estático. Abra no navegador para ver;
  os links da barra lateral navegam entre elas. São referência visual, não código
  para portar: a implementação é GTK4/libadwaita.
- Os valores de dados nas telas (gerações, tamanhos, revisões) são ilustrativos.
- `icons/zelador.svg`: ícone do app para 48px ou mais.
- `icons/zelador-small.svg`: variante para 32px e 16px.
